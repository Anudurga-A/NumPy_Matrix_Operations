# NumPy_Matrix_Operations

## Aim
To create two matrices using NumPy and perform basic matrix operations.

## Objective
To understand matrix addition, subtraction, multiplication, and transpose using Python.

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## Operations Performed
1. Matrix Addition
2. Matrix Subtraction
3. Matrix Multiplication
4. Matrix Transpose

## Description
This project demonstrates basic matrix operations using the NumPy library in Python. Two matrices are created using `np.array()`. Addition and subtraction are performed using arithmetic operators, matrix multiplication is performed using `np.dot()`, and transpose is calculated using `.T`.

## Sample Matrices
Matrix A:
[[1, 2],
 [3, 4]]

Matrix B:
[[5, 6],
 [7, 8]]

## Results
- Addition: [[6, 8], [10, 12]]
- Subtraction: [[-4, -4], [-4, -4]]
- Multiplication: [[19, 22], [43, 50]]
- Transpose of A: [[1, 3], [2, 4]]
- Transpose of B: [[5, 7], [6, 8]]

## Conclusion
Successfully performed matrix addition, subtraction, multiplication, and transpose using NumPy. This task helped in understanding basic matrix operations used in data science and machine learning.
